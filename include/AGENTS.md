# AGENTS.md — include

## Purpose

Interfaces shared across the repo: the reconstructed private Apple headers that
`AirportItlwm` builds against, the HAL abstraction both kexts drive, and the userspace
control interface.

## Ownership

- `Airport/` — reconstructed private Apple IO80211/IOSkywalk classes. Delegated to its own
  AGENTS.md; do not edit those files from this level's rules alone.
- `HAL/` — `ItlHalService`, `ItlDriverInfo`, `ItlDriverController`. The abstraction every
  Intel HAL in `itlwm/hal_*` implements and both kexts call.
- `ClientKit/` — `Common.h`, `IoctlId.h`. The ioctl contract with HeliPort.
- `FwData.h` — firmware blob descriptors consumed by the generated `FwBinary.cpp`.

## Local Contracts

- `ClientKit/` is a published interface: HeliPort builds against these headers. Changing an
  existing `IoctlId` value or struct layout breaks installed clients — add new entries
  rather than renumbering.
- `HAL/` changes ripple to every `itlwm/hal_*` implementation. A new pure virtual on
  `ItlHalService` must be implemented in `hal_iwm`, `hal_iwn`, and `hal_iwx` together.
- `FwBinary.cpp` in this folder is generated by the `fw_gen` target and gitignored. Never
  edit or commit it.

## Work Guidance

- Keep these headers buildable in the kernel environment: no libc++, no exceptions, no RTTI.

## Verification

Both kexts consume these headers, so build `itlwm` and at least one `AirportItlwm-*` target
after any change here:

```bash
xcodebuild -jobs 8 -target itlwm -configuration Release build
xcodebuild -jobs 8 -target "AirportItlwm-Sonoma14.4" -configuration Release build
```
